# Self-hosted fonts

These fonts come from the Google Fonts repository and are distributed under the
SIL Open Font License 1.1. The full copyright and license texts are included in
`Jost-OFL.txt` and `NotoSansTC-OFL.txt`.

- Jost variable, source: https://github.com/google/fonts/blob/91b26e2e0231f5aa85f5470a7b23d6d732ab15fc/ofl/jost/Jost%5Bwght%5D.ttf
- Noto Sans TC variable, source: https://github.com/google/fonts/blob/b950a7257470b900078f2bf3223823a8602de7e1/ofl/notosanstc/NotoSansTC%5Bwght%5D.ttf

The WOFF2 files were converted from the complete original TTF fonts using
fontTools 4.60.1; no glyph or language subsetting was applied. Noto Sans TC is
about 5.4 MB and is intentionally not preloaded. These are the same font
families and variable weight ranges used by the former Google font imports.
